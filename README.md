# BikeMeteo

Минимальное Android-приложение на **Kotlin + WebView** с анимированным GIF-метеорадаром: https://goldwing.dedyn.io/index.php

## Локальное кэширование GIF

- Анимация хранится во внутреннем постоянном хранилище Android (filesDir/radar.gif); не исчезает после перезапуска приложения или обновления APK.
- При запуске сразу отображается кэшированный GIF, без обращения к серверу.
- **Автоматическая загрузка** только если GIF отсутствует или кэш старше **600 секунд**. Старая анимация остается на экране, пока загружается новая.
- **Ручное обновление**: кнопка ↻ всегда видна, но неактивна первые **300 секунд** после успешного обновления. По истечении 300 секунд активируется автоматически — без HTTP-запросов. Если кэша нет, можно повторить попытку сразу.
- Возле кнопки показано время с момента последнего скачивания или состояние загрузки. Если сервер недоступен, приложение продолжает показывать старый GIF.
- Нет периодических фоновых запросов: каждую секунду обновляется только локальная надпись на экране.
- Новые данные сначала сохраняются во временный файл, проверяются на сигнатуру GIF и затем атомарно заменяют старую версию.
- WebView берет GIF из локального файла посредством shouldInterceptRequest и продолжает показывать анимацию с **pinch-to-zoom и прокруткой**. Когда новый GIF готов, обновляется только src картинки: веб-страница целиком не перезагружается.

Время кэша отсчитывается от **последнего успешного скачивания на устройство**, а не от даты отдельного радарного кадра.

## GitHub Actions и подпись

Workflow: **Actions → Build signed BikeMeteo APK**. Каждая сборка получает более высокий versionCode (github.run_number) и версию 0.1.N.

Постоянный applicationId: io.github.zoychikf1.bikemeteo.

В **Settings → Secrets and variables → Actions → Repository secrets** используются:
- ANDROID_KEYSTORE_BASE64 — PKCS#12 keystore в Base64.
- ANDROID_SIGNING_PASSWORD — пароль keystore и ключа.

Ключ можно использовать тот же, что для NMEA Bridge, с alias nmea_bridge. Если ключ отдельный, задайте **Repository variable** ANDROID_KEY_ALIAS.

В Actions можно скачать артефакт с подписанным APK и установить его поверх предыдущей версии приложения. Ключ подписи и пароль следует сохранять в надёжном месте; в репозиторий их не загружать.

## Масштабирование и границы карты

В WebView используется жест **pinch-to-zoom** (1–8×) и перетаскивание одним пальцем. Перемещение ограничено краями GIF: изображение нельзя полностью увести за экран в чёрную область. Пока квадратный GIF ниже высоты портретного экрана, он закреплён у верхнего края; после достаточного увеличения его можно прокручивать вертикально и горизонтально в границах изображения. При обновлении GIF масштаб и положение сохраняются. Это реализовано локальным JavaScript; серверных запросов такие жесты не вызывают.
